# Registro de Testes e Evidências

## Ambiente de validação
- Navegador: navegador moderno (Chrome, Edge ou Firefox)
- Sistema operacional: Windows (testado)
- Estrutura do projeto: HTML estático, CSS e Bootstrap

## Evidências verificadas

### 1. Carregamento do CSS
Foi confirmado que a página carregava corretamente após o ajuste do caminho do arquivo de estilos para `assets/css/style.css`.

### 2. Validação visual da estrutura
A página foi conferida em tela para verificar se os elementos principais estavam presentes, como:
- cabeçalho;
- seção inicial com destaque;
- cards de vagas;
- blocos de tecnologias;
- seção final de conclusão;
- rodapé.

### 3. Validação visual do projeto
A visualização foi feita abrindo `index.html` diretamente no navegador para verificar o carregamento dos elementos principais e a organização visual do conteúdo.

### 4. Observações sobre o funcionamento
O resultado foi satisfatório. A navegação interna por links de âncora funcionou como esperado, o conteúdo foi exibido corretamente e a estrutura visual ficou consistente.
