# Panorama do Mercado de Tecnologia

Este projeto é uma página de apresentação acadêmica sobre o mercado de tecnologia, com foco em vagas locais e nacionais. A ideia foi reunir informações relevantes sobre as competências exigidas, as tecnologias mais citadas e as diferenças entre o cenário regional e o mercado mais amplo.

## Objetivo
O objetivo foi criar uma página clara, visualmente organizada e fácil de ler, para apresentar a análise das vagas e mostrar como o mercado de trabalho atual tem exigido conhecimentos específicos em desenvolvimento, bancos de dados, APIs e ferramentas de colaboração.

## Tecnologias usadas
- HTML5
- CSS3
- Bootstrap 5.3.8
- Git
- GitHub Pages
